================================================================================
                        TROUBLESHOOTING
================================================================================

PROBLEM: Server won't start
SOLUTION: 
- Check if port 3000 is available: lsof -i :3000
- Kill blocking process: kill -9 <pid>
- Or change port: PORT=3001 npm start

PROBLEM: Database locked
SOLUTION: Restart server (database auto-recovers)

PROBLEM: WebSocket connection fails
SOLUTION: 
- Check firewall settings
- Verify ws:// protocol support
- Check browser console for errors

PROBLEM: Numbers not auto-drawing
SOLUTION:
- Click "START GAME" button (drawing only starts after click)
- Check browser console for JavaScript errors

PROBLEM: Admin can't login
SOLUTION: Username is 'admin', password is 'admin123'

PROBLEM: Payment QR not displaying
SOLUTION: Ensure qr.png file exists in game directory

PROBLEM: Tickets not saving to database
SOLUTION:
- Verify tickets.db file has write permissions
- Check database file size > 16KB
- Restart server to reinitialize database
