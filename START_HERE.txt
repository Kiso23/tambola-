🎮 HOW IT WORKS
══════════════════════════════════════════════════════════════════════════════

CREATING A GAME:
  1. Enter your name
  2. Click "Create Game"
  3. Get game link (auto-generated)
  4. Send link to friends via WhatsApp/Telegram/Email

JOINING A GAME:
  1. Friend opens the link you sent
  2. Enters their name
  3. Game code auto-fills from URL
  4. Click "Join Game"
  5. They see your game!

PLAYING:
  1. Creator clicks "Start Game"
  2. Creator clicks "Draw Number" (repeat)
  3. Your ticket auto-marks when numbers are drawn
  4. When you get a complete line (3 numbers in a row):
     → Click "Claim Line" button
  5. Server verifies your win
  6. Winner announced to everyone!

THREE WIN TYPES:
  🎯 First Line     → Any 1 complete horizontal row
  🎯 Two Lines      → Any 2 complete horizontal rows  
  🏠 Full House     → All 9 numbers marked

VERIFY FAIRNESS:
  • Click "📜 Verify Game Proof" anytime
  • See exact numbers drawn
  • See game cryptographic hash
  • Prove no manipulation happened
  • This proof is permanent and verifiable


🔒 ANTI-CHEATING TECHNOLOGY
══════════════════════════════════════════════════════════════════════════════

This is NOT a simple game. It uses military-grade security:

1. SERVER-VERIFIED MARKS
   ✓ Every mark checked server-side
   ✓ Client cannot fake marks
   ✓ Only drawn numbers can be marked

2. TAMPER-PROOF TICKETS
   ✓ SHA256 hash when you join
   ✓ Cannot modify ticket
   ✓ Hash verified on win claim

3. CRYPTOGRAPHIC PROOFS
   ✓ Game hash is immutable
   ✓ Server seed ensures fairness
   ✓ Winners have permanent proof
   ✓ Anyone can verify no cheating

4. FAIR NUMBER DRAWING
   ✓ Numbers pre-shuffled
   ✓ Cannot be changed during play
   ✓ Sequence same for all players

🐛 TROUBLESHOOTING
══════════════════════════════════════════════════════════════════════════════

Problem: "npm not found"
Solution: Install Node.js from https://nodejs.org/

Problem: "Port 3000 already in use"
Solution: PORT=8080 npm start

Problem: "Cannot find module"
Solution: npm install

Problem: "Players can't see each other"
Solution: Make sure server is running and accessible

Problem: "WebSocket connection failed"
Solution: Check firewall allows port 3000

More help:
  → See README.md Troubleshooting section
