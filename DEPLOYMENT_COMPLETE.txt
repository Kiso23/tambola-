Q: Numbers not drawing?
A: Click "START GAME" button. Drawing only starts after clicking START.

Q: Admin login failed?
A: Username: admin, Password: admin123 (case-sensitive)

Q: Can't connect?
A: Check if port 3000 is free: lsof -i :3000
   Kill blocking: kill -9 <pid>

Q: Database errors?
A: Restart server. If persists, delete tickets.db and restart.

Q: WebSocket disconnects?
A: Check firewall and network. Auto-reconnect is enabled.

Q: Players can't see changes?
A: Refresh browser. Check browser console for errors.

Q: Need more players?
A: Edit app.js/server.js, change: gameState.players.size >= 80

Q: How to change admin password?
A: Edit server.js line 1: ADMIN_CREDENTIALS

Table: tickets

  id (INTEGER PRIMARY KEY)
  ├─ Type: Auto-incrementing unique identifier
  ├─ Purpose: Unique ticket ID
  ├─ Example: 1, 2, 3, 4, 5, 6

  playerName (TEXT NOT NULL)
  ├─ Type: Text string
  ├─ Purpose: Player's name
  ├─ Example: "kiso", "jgg", "TestPlayer", "DeployTest"

  ticket (TEXT NOT NULL)
  ├─ Type: JSON string (3x9 grid)
  ├─ Purpose: Ticket numbers
  ├─ Example: [[0,13,0,34,44,53,0,71,0],[3,16,23,0,0,0,0,73,81],[0,0,0,39,41,59,70,76,0]]

  purchasedAt (DATETIME)
  ├─ Type: Timestamp
  ├─ Purpose: Purchase date/time
  ├─ Example: "2026-11-07 18:18:18"

  used (BOOLEAN)
  ├─ Type: 0 or 1
  ├─ Purpose: Ticket used in game
  ├─ Example: 0 (not used), 1 (used)
