🔒 Anti-Cheating Technology

This game uses multiple layers of security to ensure absolutely fair play. No manipulation is possible at any level.

The Four Pillars of Fairness

  • Server-Verified Marking
    Every mark is checked server-side. Client cannot claim numbers they don't have. Only actually drawn numbers can be marked.
  • Tamper-Proof Tickets
    Each ticket gets a SHA256 hash when joining. Ticket cannot be modified. Hash verified on every win claim.
  • Cryptographic Proofs
    Game hash is immutable. Server seed ensures deterministic number sequence. Winners have mathematical proof.
  • Fair Number Drawing
    Numbers are pre-shuffled using server seed. Cannot be manipulated by any player. Same sequence for all.

Step 2: Game starts → Server seed locks number sequence
Step 3: Numbers drawn → Auto-marked on ticket
Step 4: Win claimed → Server verifies marks match ticket

Result: Even if player is an advanced hacker, they cannot:

  • Modify their ticket after joining
  • Mark numbers they don't have
  • Change drawn numbers
  • Fake a win that didn't happen
  • Alter game history or proofs

❓ FAQ

Q: Can anyone cheat?

No. The server verifies every mark and win. Cheating is mathematically impossible.

Q: What if server crashes?

Games are in memory. But you have cryptographic proof of the entire game history which cannot be forged.

Q: Can I play with people outside my WiFi?

Yes! Use your local IP address. See QUICK_START.md for details.

Q: How many players can join?

Unlimited! The server can handle hundreds of simultaneous players.

Q: Is it really free?

Yes! 100% open source. Use for Diwali and beyond, no cost, no ads.
