HOW THEY WORK TOGETHER:
=======================

STARTUP:
--------
1. npm start
2. Runs: node server.js
3. Server starts on port 3000
4. Server hosts index.html

WHEN PLAYER VISITS localhost:3000:
-----------------------------------
1. Browser downloads index.html
2. Browser loads all CSS & JavaScript
3. Player sees welcome screen
4. Player can Create or Join game

CREATING A GAME:
----------------
1. Player clicks "Create Game"
2. Browser sends POST to /api/game/create
3. Server generates unique game ID
4. Server creates game instance
5. Browser gets game ID back
6. Browser connects WebSocket

JOINING A GAME:
---------------
1. Player enters game code
2. Browser connects WebSocket
3. Browser sends "join_game" message
4. Server adds player to game
5. Server broadcasts "player_joined"
6. All players see new player join

PLAYING:
--------
1. Creator clicks "Start Game"
2. Browser sends "start_game" to server
3. Server generates random sequence
4. Server creates game hash
5. Creator clicks "Draw Number"
6. Server returns next number
7. Browser auto-marks ticket
8. All players see number drawn
9. Repeat until win

CLAIMING WIN:
-------------
1. Player clicks "Claim Line/House"
2. Browser sends "claim_win" to server
3. Server verifies marks vs drawn numbers
4. Server checks ticket hash (unchanged)
5. Server confirms or rejects win
6. Browser shows result
7. All players see winner


KEY SECURITY POINTS:
====================

✓ Server verifies EVERY mark
  → Client JavaScript cannot fake
  → All logic runs server-side too

✓ Ticket hash prevents modification
  → SHA256 hash stored at join
  → Hash checked on every win claim
  → Any ticket change = hash mismatch

✓ Numbers pre-shuffled deterministically
  → Server seed makes sequence unchangeable
  → Same for all players
  → Cannot draw same number twice

✓ Game hash is immutable
  → Created at game start
  → Contains all player info
  → Cannot be changed
  → Proof of what happened

✓ WebSocket communication verified
  → Only valid game codes accepted
  → Only players in game can send messages
  → All messages validated server-side
