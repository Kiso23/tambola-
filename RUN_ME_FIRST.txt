🎮 HOW TO PLAY IN 60 SECONDS
════════════════════════════════════════════════════════════════════════════════

CREATING A GAME:
   1. Enter your name (e.g., "Priya")
   2. Click "Create Game"
   3. Get game link - Share it! 🔗

JOINING A GAME:
   1. Get link from game creator
   2. Game code auto-fills
   3. Enter your name
   4. Click "Join Game"

PLAYING:
   1. Creator clicks "Start Game"
   2. Creator clicks "Draw Number" (repeatedly)
   3. Your numbers auto-mark
   4. When you complete a line → Click "Claim Line"
   5. Win! 🏆

🛠️ TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

❌ "npm: command not found"
   → Install Node.js from https://nodejs.org/

❌ "Port 3000 already in use"
   → Run: PORT=8080 npm start

❌ "Cannot find module"
   → Run: npm install

❌ "WebSocket connection failed"
   → Check firewall allows port 3000

❌ "Players can't see each other"
   → Make sure server is running
   → Check browser network tab for errors
